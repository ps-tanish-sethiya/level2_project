# Merge Conflict Markers Left in Code

## Symptom
Python build or test compilation fails with `SyntaxError: invalid syntax` pointing to lines containing `<<<<<<< HEAD`, `=======`, or `>>>>>>> branch-name`.

## Root Cause
An engineer resolved a Git merge or rebase locally but committed the file without removing the conflict marker lines generated by Git version control.

## Recommended Fix
Search the repository for conflict markers using `git grep -E "^(<<<<<<<|=======|>>>>>>>)"`. Manually resolve the conflicting code blocks in the affected files, delete all conflict marker lines, and commit the clean changes.
